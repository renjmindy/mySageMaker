# Chart Selection - Handler Contactor Data

| Question | Form | Notes |
|---|---|---|
| Where on the HIFIX are the closed sites? | 16-column grid heatmap, row 32/16 on top | match the handler screen; one grid per side; sequential single hue |
| How is availability moving? | line, one y-axis, front vs rear | direct labels + legend; never dual axis |
| Which sites matter most? | ranked bar / Pareto of lost capacity | top-N with cumulative % |
| When did a set of sites open/close? | event timeline (one row per cluster) | pair with RCA notes |
| Headline number | stat tile with caveat | include range or completeness label |

Avoid: pie charts for closed vs open (always ~90/10), 3D, rainbow scales, one colour per site.
