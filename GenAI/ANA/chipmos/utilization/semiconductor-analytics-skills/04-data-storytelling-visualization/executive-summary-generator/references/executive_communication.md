# Executive Communication Notes

- Replace "closed site (grey cell)" with "test position that cannot test".
- Say "capacity" not "availability" when the audience thinks in units per hour.
- Always pair a number with its range or caveat; managers distrust single exact figures from OCR-derived data.
- State what is NOT yet measured (OEE factors) so the headline is not over-read.
- Use the glossary in `05-stakeholder-communication/technical-to-business-translator`: "test position" for site, "out of service" for closed, "unreadable screen reading" for read failure. OEE is allowed for fab and operations managers; spell it out once.
- Numbers must be traceable: round them to the precision a manager needs, but every figure has to match the analysis document after rounding (the checker verifies this).
