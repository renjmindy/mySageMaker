# Learnings Log - handler contactor capacity, Sep-Oct 2026

A row whose "repeat of" names an earlier learning is a lesson that did not hold: the same class of defect came back. "Found by": `automated` (a check failed), `evaluation` (a review of that skill), `analyst` (found while working), `user` (the user's question). "Source": a commit or a file that shows it.
