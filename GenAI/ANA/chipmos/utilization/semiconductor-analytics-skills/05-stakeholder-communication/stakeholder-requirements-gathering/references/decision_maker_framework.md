# Decision-Maker Framework

|---|---|---|
| Equipment / maintenance lead | when to replace contactors / HIFIX boards | ranked clusters, recoverable points, event times |
| Production planner | scheduling around downtime | availability trend, planned vs actual |
| Data/IT owner | capture pipeline changes | data-quality findings, schema |
| Process engineer | root cause validation | event timeline, block alignment |
