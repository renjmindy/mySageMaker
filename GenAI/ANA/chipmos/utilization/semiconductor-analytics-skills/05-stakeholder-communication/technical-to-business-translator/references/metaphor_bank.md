# Metaphors

A metaphor is allowed only if it keeps the structure of what it explains; otherwise leave it out.

- **Contactor grid = a parking lot**: each space is a test position; blocked spaces cut the number of cars (units) handled at once. Keeps: parallel positions, closures reduce capacity. Does not keep: which spaces are blocked matters for repair planning (use the grid picture instead).
- **OEE = a factory report card with three marks that all have to be good**: was it running (availability), was it fast (performance), was the output good (quality); the overall grade multiplies them. Earlier versions said "batting average", which is a single ratio and hides that OEE is a product of three.
- Do not use an analogy for statistical uncertainty ("plausible range"); say it in numbers: "between 90.6% and 92.1%".
